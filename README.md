# hapcha-site

The public web pages for the hapcha iOS app: the home page, support, and the privacy policy.
App Store Connect links to the support and privacy pages.

It is plain HTML. Vercel publishes each push to `main` at https://hapcha.vercel.app.

If the app starts to collect a new kind of data, update `privacy.html`, the app's
`PrivacyInfo.xcprivacy`, and the App Privacy answers in App Store Connect together.
